# Rolph Studio

Static GitHub Pages version of Rolph Studio.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `.nojekyll` — tells GitHub Pages to serve the static files directly

## Publish with GitHub Pages
1. Create a GitHub repository named `rolph-studio`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will provide the public Pages address after deployment.

## Editing
Open `index.html` to change words/links and `style.css` to change the design.
